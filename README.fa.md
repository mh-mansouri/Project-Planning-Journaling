یک Skill برای [Claude](https://claude.ai) که پیش از نوشتن حتی یک خط کد به شما کمک می‌کند
دامنهٔ پروژه را درست تعریف کنید، و سپس یک مستند/ژورنال زنده از هر اتفاقی که در طول پروژه
می‌افتد نگه می‌دارد.

یک نشست کاملاً تازه را چند هفته بعد باز کنید، Claude را به فایل `project-journal/README.md`
ارجاع دهید، و او دقیقاً می‌داند کار از کجا متوقف شده — بدون نیاز به مرور تاریخچهٔ
گفتگوهای قبلی.

صفحه را به چت ترجیح می‌دهید؟ [`index.html`](./index.html) یک نمای کلی ایستا با همان
لینک‌های نصب است — پس از فعال‌سازی GitHub Pages (از مسیر Settings → Pages → Deploy from
branch → `main` / `/root`) در آدرس زیر در دسترس خواهد بود:
`https://mh-mansouri.github.io/Project-Planning-Journaling/`
یا همین حالا فایل را به‌صورت محلی باز کنید، نیازی به سرور نیست.

## کاری که انجام می‌دهد

- **دریافت اطلاعات اولیهٔ پروژه** — پیش از دست‌زدن به کد، دربارهٔ نوع پروژه، اینکه آیا
  مخزن Git از قبل وجود دارد (و اگر نه، نامی، سطح دسترسی، و مجوزی پیشنهاد می‌دهد)، اهداف
  کوتاه‌مدت در برابر بلندمدت، و اینکه آیا این پروژه باید عمومی/متن‌باز بماند یا احتمالاً
  بعداً به یک محصول خصوصی تبدیل شود، سؤال می‌پرسد.
- **پوشهٔ `project-journal/` را می‌سازد** — جدا از کد منبع، با یک داشبورد `README.md`،
  یک لاگ `decisions/`، کدهای واقعی در `snippets/`، و یادداشت‌های اختیاری برای هر نشست.
- **یک داشبورد قابل‌مرور سریع می‌نویسد** — زبان ساده، جدول‌ها و نمودارهای Mermaid
  به‌جای نثر، چک‌لیست برای هر نقطهٔ عطف، و بخش‌های تاشوندنی برای هر چیز طولانی.
- **خودش را به‌روز نگه می‌دارد** — پس از هر گام، تصمیم، commit یا push مهم، نقشهٔ راه،
  لاگ تصمیم‌ها، تاریخچهٔ Git و گام‌های بعدی را خودکار به‌روزرسانی می‌کند.
- **یک روش توسعه را برای انتخاب پیشنهاد می‌دهد** — spec-first (برنامه‌ریزی کامل پیش از
  شروع)، interactive/iterative (انعطاف‌پذیر، ژورنال تصمیم‌ها را پس از وقوع ثبت می‌کند)،
  یا یک ترکیب مبتنی‌بر نقطهٔ عطف (hybrid).
- **یک بازبینی دوره‌ای هم انجام می‌دهد، نه فقط به‌روزرسانی‌های رویدادمحور** — با هر
  فاصلهٔ زمانی که انتخاب کنید (پیش‌فرض: هفتگی): بررسی می‌کند که همهٔ لینک‌ها هنوز کار
  می‌کنند، هیچ تصمیمی بی‌سروصدا نقض نشده، هیچ موردی در نقشهٔ راه بدون توجه رها نشده، و
  منابع بیرونی ذکرشده (اگر باشند) هنوز معتبر هستند، نه فقط اینکه هنوز آنلاین‌اند.

## نصب

**گزینهٔ A — یک کلیک (ساده‌ترین):**
[`project-planning-journaling.skill`](./project-planning-journaling.skill) را دانلود
کنید، در Claude بازش کنید و روی **Save skill** بزنید. (باید قابلیت ذخیرهٔ Skill برای
حساب یا سازمان شما فعال باشد.)

**گزینهٔ B — از پوشهٔ منبع:**
پوشهٔ [`project-planning-journaling/`](./project-planning-journaling) را در پوشهٔ
Skillهای خودتان کپی کنید.

**گزینهٔ C — هر چت هوش مصنوعی دیگر (ChatGPT، Grok، Gemini، Copilot، DeepSeek و...):**
محتوای [`universal-prompt.md`](./universal-prompt.md) را در اولین پیام خود کپی کنید —
بدون نصب، بدون آپلود فایل، همه‌جا کار می‌کند.

## استفاده از آن

فقط به Claude بگویید که در حال شروع (یا ازسرگیری) یک پروژه هستید، مثلاً:

> دارم یک پروژهٔ جانبی جدید شروع می‌کنم — یک ابزار CLI برای تغییر نام دسته‌ای عکس‌ها.
> بیا پیش از نوشتن کد برنامه‌ریزی‌اش کنیم.

یا، روی یک پروژهٔ موجود:

> برای هر چیزی که تا الان ساختیم یک ژورنال پروژه بساز و از این به بعد به‌روزش نگه دار.

یا، برای ازسرگیری:

> ژورنال پروژه را باز کن و بگو کجا متوقف شده بودیم.

## نکتهٔ مهم

این Skill از ابتدا می‌پرسد که آیا پروژه باید عمومی/متن‌باز بماند یا احتمالاً بعداً به
یک شاخهٔ خصوصی منشعب و به‌عنوان یک محصول مستقل توسعه یابد — اما تصمیم واقعی (و هر
پیگیری حقوقی/مجوزی) بر عهدهٔ شماست. این Skill آن را ثبت می‌کند، به‌جای شما تصمیم
نمی‌گیرد.

## مبتنی بر پژوهش و رویه‌های تثبیت‌شده

این گام‌ها از هیچ ساخته نشده‌اند — بر پایهٔ ده منبع آزادانه در دسترس (رکوردهای تصمیم
معماری، چارچوب‌های مستندسازی، قراردادهای changelog و commit، روش‌شناسی فاز کشف، Scrum)
به‌علاوهٔ پنج کتاب/استاندارد منتشرشدهٔ تجاری که فقط مفهومشان ذکر شده است. فهرست کامل،
شواهد معتبر بودن هر منبع (نه صرفاً اولین نتیجهٔ جست‌وجو)، و اینکه هر کدام پشتوانهٔ کدام
گام است، در [`references/research.md`](./project-planning-journaling/references/research.md).
این مخزن، گام ششمِ خودِ Skill را هم اجرا می‌کند: دو Action هفتگی در GitHub این فهرست را
به‌روز و صادق نگه می‌دارند — یکی همهٔ لینک‌ها را دوباره بررسی می‌کند، دیگری برای بازبینی
اعتبار منابع یک issue یادآوری باز می‌کند.
